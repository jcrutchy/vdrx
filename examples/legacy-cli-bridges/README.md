# legacy-cli-bridges

Demos of the **old** `cli_bridges` forms (cgi, bus, bus-daemon). Still supported; new setups should use the other examples. Needs `php`.
Run `../../bin/vdrx` from this folder, then try `/cli/index.php`, `/hello/x`, `/template-demo?name=Jared`, `/echo-daemon`.
See [legacy-cli-bridges.md](../../docs/legacy-cli-bridges.md).
